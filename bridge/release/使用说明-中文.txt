Codex Micro 桌面同步桥接 v1.0.1

1. 保持本文件夹内全部文件在一起，不要单独移动 exe。
2. 先打开 Windows 版 Codex，进入需要控制的当前对话。
3. 双击“CodexMicroBridge.exe”或“启动中文桥接.cmd”。
4. 看到“桌面同步可用”后，打开手机 APP；首次使用再扫码配对。
5. 手机与电脑应连接同一局域网，不需要开启 VPN。

使用说明：
- 手机文字发送到电脑端当前 Codex 输入框，并自动发送。
- 手机长按批准会确认当前桌面的同一个权限请求，效果相当于在该审批上确认或按回车。
- 遇到 Computer Use 权限时，普通批准只选择“允许此对话”，不会自动选择“始终允许”。
- 桌面对话切换后，手机控制目标也随之切换。
- 点击手机端“最近回复”可进入完整对话历史页。
- 请不要在手机发送或批准的瞬间切换 Windows 窗口；桥接检测到目标变化会主动拒绝操作。

升级说明：
- v1.0.1 会继续使用 %LOCALAPPDATA%\CodexMicroBridge 中原有的证书和配对数据。
- v1.0.0 与 v1.0.1 APK 的签名证书不同，Android 会拒绝直接覆盖安装。从 v1.0.0 升级时需先卸载旧 App，再安装 v1.0.1 并重新配对；卸载会清除手机端配对和历史数据。
- 本版不再依赖随包附带的 codex.exe，也不再创建独立 App Server 任务。
- v1.0.1 会调用当前输入框右侧经核验的“发送”按钮，并验证输入框已经提交，不再依赖模拟回车。
- 在“诊断”页点击“发送手机审批测试”，手机批准后应启动记事本；拒绝时不得执行任何操作。
- 临时断线或请求取消会自动重连，不再误报为配对失效；手机端已保存的完整长回复不会被快照预览覆盖。
- 任务完成后，上方状态卡只显示“完成/未读”和状态底色；完整正文统一显示在“最近回复”卡片。
- 本版修复真实 Computer Use 审批遮挡输入框时误报“电脑服务降级”的问题，并为桌面程序加入 EXE、窗口和托盘图标。
