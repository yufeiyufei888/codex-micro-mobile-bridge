# Codex Micro V1.0.3 更新说明

V1.0.3 是 V1.0.2 实机失败后的阻断修复版，优先恢复可靠的新回复同步和 Computer Use 手机审批状态闭环。

## 修复内容

- 将会话文件同步移到桌面 UI Automation 检查之前并独立执行；桌面控件树刷新或越界异常不会再跳过消息同步。
- 用“上次文件字节位置”代替固定 2 MiB 尾部窗口，精确读取新增数据；如果上次位置位于未写完的 JSON 行中，会向前找到该行开头并在下一次补全解析。
- 保留 canonical `response_item` 消息 ID 去重和完整对话历史。
- 捕获 Chromium 虚拟控件集合在枚举期间变化产生的 `ArgumentOutOfRangeException`，避免每秒诊断刷屏。
- 审批测试完成后任务立即恢复为空闲；真实桌面审批完成后任务立即恢复为运行，不再停留在“待审批”。

## 真实失败样本验证

- 当前真实 Codex 会话文件中，手机用户消息写入时间为 2026-08-12 13:20:25，助手“收到。”写入时间为 13:20:44。
- 新增的增量读取测试从用户消息的真实文件字节位置开始，已成功找到该助手消息的 canonical 消息 ID。

## 验证边界

- 自动测试验证解析、状态归一化、协议与构建产物；不能替代 Windows + 红米 K80 Pro 的真实 WSS、Computer Use 按钮点击和覆盖安装验收。
- 若 V1.0.3 实机仍不能稳定同步回复，将回退到 V1.0.0 的“仅最近回复”路线并停用历史页，优先保证核心收发与审批可用。
