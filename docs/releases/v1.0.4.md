# Codex Micro v1.0.4（历史版本）

> 该版本仍存在固定落后一轮的消息同步问题，不推荐日常使用。对应标签是二进制证据归档，不声明包含完整 v1.0.4 源码。

## 主要变化

- 同一桌面对话开始新一轮任务时保持已验证的会话文件绑定，仅在真正切换对话时重新选择会话。
- Windows 与 Android 两端清洗审批控件树中的通用碎片。
- 审批卡按状态、当前会话、请求标题、请求内容、工作目录、实际操作、批准和拒绝重新分层。

## 验证与已知问题

- 自动验证：Windows 78 项、Android 28 项、protocol 38 cases / 1 pair。
- 审批页面可读性有所改善。
- 电脑直接发送后手机仍不能即时同步；手机发送新消息时只能补出上一轮内容。
- 手机可能显示已连接，而电脑显示桌面同步未就绪。
