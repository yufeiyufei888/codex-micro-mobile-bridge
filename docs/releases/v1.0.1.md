# Codex Micro v1.0.1（历史版本）

> 该版本加入历史记录、真实审批识别和统一图标，但后来确认消息同步仍不稳定，不应描述为当前推荐稳定版。`v1.0.1` 标签是在工作区继续演进前已导入并发布的源码标签，现保持不可移动。

## 主要变化

- Computer Use 审批弹窗遮住输入框时，Bridge 优先识别审批，不立即判定服务降级。
- 手机普通批准只映射“允许此对话”，拒绝只作用于当前审批。
- 状态卡不再重复完整回复；新增“最近回复”和完整对话历史页。
- 对话历史写入 Android Room，重连或重新进入详情页后可以恢复。
- Windows EXE、主窗口和托盘使用统一 Codex Micro 图标。

## 已知问题

- v1.0.0 与 v1.0.1 的 APK 签名不同，首次升级必须卸载 v1.0.0。
- 新回复实时同步和真实 Computer Use 适配仍不完整。
