# Codex Micro V2.0.3 Windows 桌面对话身份热修复说明

## 问题

V2.0.2 已能识别新版 Codex Desktop 的常规标题栏，但一次回复完成后，标题区域可能短暂显示“查看活动，需要关注”等动态入口。旧逻辑把该文字当作当前对话标题，找不到唯一对应的本地会话后，将桌面同步标为降级。表现为：手机消息已经成功发送、电脑也正常回复，随后手机却显示“当前 Codex 桌面对话尚未唯一匹配到会话记录”。

这不是 WSS、证书、配对或局域网断开，而是桌面对话身份识别发生了短暂误判。

## 修复

- 将“查看活动”“打开已安排任务”“View activity”“Open scheduled tasks”等动态标题栏入口排除在对话标题候选之外。
- 当标题短暂不可识别，但之前的当前会话已经唯一确认时，继续保留该会话用于接收状态和回复，不再立刻把整个桌面服务标为降级。
- 在身份重新唯一确认之前将手机发送入口锁定，避免把消息写入错误对话。
- 标题恢复后自动恢复可发送状态，不需要重新配对、清空数据或重启手机。
- 保留 V2.0.1 的六会话快照容量修复与 V2.0.2 的新版标题栏过滤。

## 兼容性与升级

- Windows Bridge：2.0.3。
- Android：继续使用 2.0.0；协议、证书、配对与数据库兼容，不需要重新安装 APK。
- 退出旧 Bridge 后，直接运行 V2.0.3 文件夹内的 `CodexMicroBridge.exe`。
- `%LOCALAPPDATA%\CodexMicroBridge` 中的证书、配对设备和本地会话数据继续使用。
