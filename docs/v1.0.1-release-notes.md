# Codex Micro V1.0.1 更新说明

V1.0.1 是 V1.0.0 实机验收后的问题修复版，重点收口真实 Codex Computer Use 审批、回复展示与 Windows 程序图标。

## 主要修复

- 真实审批优先识别：Computer Use 弹窗遮住或替换输入框时，桥接仍会识别待审批状态，不再误报“电脑服务降级”。
- 安全的一次批准：手机“批准”只映射电脑端“允许此对话”；“始终允许”不会被普通批准误触发；拒绝只映射当前审批的拒绝按钮。
- 回复展示去重：顶部状态卡只展示状态、图标和链路，不再重复“最近回复”的完整正文。
- 完整对话历史：手机可从“最近回复”进入历史页，查看手机发送、电脑直接发送和 Codex 回复；历史记录持久化保存并在重连后恢复。
- 桌面图标：Windows EXE、主窗口与托盘统一使用 Codex Micro 图标，资源管理器不再显示通用程序图标。

## 保留的 V1.0.0 能力

- 手机输入直接发送到电脑当前 Codex 对话。
- 长回复完整同步。
- Wi-Fi 断开后自动恢复，并从第 1 次重新计算本轮重连次数。
- 红米/小米后台与锁屏持续连接模式。
- 桥接自带审批批准/拒绝测试与一次性执行保护。

## 验证边界

- 自动验证覆盖 Windows 解决方案编译、桌面单元测试、Android JVM 测试、APK 构建和协议 fixture。
- 真实 Computer Use 弹窗仍必须在安装 V1.0.1 后由用户执行一次手机批准与拒绝实机验收；自动测试只能验证控件名称分类、一次批准映射和去重逻辑，不能替代真实桌面 UI 操作。
