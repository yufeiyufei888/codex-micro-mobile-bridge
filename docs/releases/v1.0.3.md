# Codex Micro v1.0.3（历史版本）

> 该版本保留为真实 Computer Use 审批链路的重要实机证据。对应标签是二进制证据归档，不声明包含完整 v1.0.3 源码。

## 主要变化

- 将会话文件同步从易变化的 Windows UI Automation 检查中拆出，先同步会话，再检查输入框和审批控件。
- 按上次文件字节位置增量读取新增 JSONL；遇到未写完的半行时退回行首，等待下一轮补齐。
- 捕获 Chromium 虚拟控件集合变化引发的 `ArgumentOutOfRangeException`，避免持续刷屏并阻塞同步。
- Bridge 审批测试和真实审批完成后恢复正确运行状态，主页退出“待审批”。

## 实机结论与已知问题

- 手机主动发送消息后，回复能够自动出现，不需要刷新或重连。
- 真实 Computer Use 手机长按批准通过，操作只执行一次，手机显示“已批准”，主页退出“待审批”。
- 电脑直接发送的消息和回复仍不能即时出现，只能等手机下一次发送时补读。
