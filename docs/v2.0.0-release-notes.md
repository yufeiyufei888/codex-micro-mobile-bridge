# Codex Micro V2.0.0 更新说明

发布候选生成日期：2026-08-13。自动化门禁已通过，真实 Windows + Codex Desktop + Android 联合验收待用户完成。

## 本版重点

V2.0.0 将桌面同步从“最近活动窗口推测”改为“按稳定会话 ID 与 JSONL 生命周期事件归属”。目标是让手机上的每个对话、状态、回复与审批彼此独立。

## 新增与修复

### 多会话与状态

- 当前可操作的可见 Codex 对话固定映射到槽位 1，不再被后台活跃对话抢占。
- 当前对话与最近五个对话的回复、运行、完成未读、待审批和时间戳按各自会话保存。这六个会话是 V2.0.0 的手机同步范围，不承诺永久保存范围外的全部桌面历史。
- 状态从 Codex 本地 JSONL 的 `task_started`、`task_complete`、`turn_aborted` 事件归一化；完成且未读显示绿色，运行显示蓝色。
- 轮询未检测到新消息时不再刷新更新时间，避免所有任务都被错误判断为“最近运行”。

### Goal、计划与提问界面

- Goal、计划、提问等界面出现附加卡片或临时没有普通输入框时，不再把网络与会话同步标为“电脑服务降级”。
- 该状态下仍同步对话、回复和审批；只有发送入口会在没有可靠输入框时暂不可用。

### 审批

- 审批与所属会话、当前桌面控件指纹绑定，避免把一个对话的批准执行到另一个对话。
- 可见对话标题无法唯一匹配时，立即清除旧绑定并使旧审批失效；只有重新确认到稳定会话 ID 后才允许手机发送、停止或审批。
- 手机审批请求改为优先显示简短的操作和目标，例如“请求使用电脑功能：notepad”。
- 仍保留长按 0.6 秒批准、拒绝按钮和执行前二次复核。

### Android 客户端与数据

- 移除演示模式和演示数据，不再出现虚拟任务。
- Room 升级到 v4：只删除历史演示行及其孤儿记录，保留真实对话与真实消息。
- Release 启用 R8 混淆和资源压缩；保持单一通用 APK，不为某一手机型号做专用包。
- 使用白色开发者工具风格：48dp 触控目标、状态卡全底色、图标与文本共同表达状态。

## 本地自动化验证

- Windows Bridge：96/96 项 Release 测试通过，覆盖协议、会话读取、生命周期、状态隔离、已读状态、审批摘要和对话身份门禁。
- 协议：38 个 fixture 用例与 1 组请求/响应对全部通过。
- Android：10 个测试套件、33/33 项 JVM 测试通过；Release APK、AndroidTest APK 编译和 `lintRelease` 全部通过。
- 通用 Release APK 为 23.04 MiB，包含 arm64-v8a、armeabi-v7a、x86 和 x86_64，不是手机型号专用包。
- APK 发布前必须校验包名、versionCode、签名连续性和单一通用产物。

## 仍需真机验收

以下不能仅由单元测试或构建结果证明，需在真实 Windows、Codex Desktop、Android 手机和同一局域网中验证：

1. 切换普通对话、Goal、计划和提问界面时，槽位 1 是否随可见对话更新且不降级。
2. 同时运行多个对话时，手机是否正确区分各自状态、回复与审批。
3. 当前对话完成后，是否显示绿色“完成·未读”，阅读后是否正确清除未读。
4. Computer Use 与普通 Codex 审批是否只作用于手机所示的同一会话。
5. 覆盖安装、Wi-Fi 切换、后台保活和锁屏恢复是否正常。

## 兼容性

- Android 包名继续使用 `com.codexmicro.mobile.debug`。
- 发布 APK 必须沿用既有签名，才能从 V1.x 覆盖安装。
- Windows 10/11 x64；Android minSdk 26，目标 SDK 36。
