# Codex Micro v1.0.6 — V1.x 已验证基础链路

> 该版本修复 v1.0.5 的严重同步回归，并已由用户在真实 Windows、Codex Desktop 与红米 K80 Pro 环境确认手机/电脑实时消息同步及 Computer Use 审批链。已知限制是多个桌面对话同时活动时可能混流，不提供可靠的多会话隔离。

## 本次修复

- 修复 v1.0.5 无法同步任何新消息和回复的严重回归。
- 会话元数据和消息尾部统一使用允许 `FileShare.ReadWrite | FileShare.Delete` 的只读文件流，兼容 Codex 正在追加写入的活动 rollout。
- 安全读取 `thread_source` 和 `parent_thread_id`，避免共享冲突或单条格式异常淘汰正确 root 会话。
- 手机发送后不再提前清除已验证的会话路径和文件游标。
- 等待精确手机提示匹配期间继续同步当前已绑定会话，不再暂停 45 秒。
- 只有 Codex 输入框和当前会话文件都可用时才显示“桌面同步可用”，并把真实状态同步给手机。

## 实机验收结果

1. 手机发送消息后，本轮 Codex 回复及时到达，无需再发第二条触发同步。
2. 电脑直接输入消息后，手机实时收到该消息与回复。
3. 真实 Computer Use 请求在手机出现；批准后只执行一次、显示“已批准”并退出“待审批”，拒绝分支正常。
4. Wi-Fi 重连计数、后台保活、锁屏恢复和长回复末尾显示在该阶段均完成过测试。

## 已知限制

- 多个 root 对话同时活动时，回复、运行状态或审批归属可能混入同一手机对话。
- v1.0.6 不声明已经解决多对话隔离；该能力由后续版本继续开发。
