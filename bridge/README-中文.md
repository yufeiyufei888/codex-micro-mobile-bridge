# Codex Micro 桌面同步桥接（Windows）

这是 Android Codex Micro 的 Windows 伴随程序。V1.0.6 采用“桌面同步模式”：手机不再创建一套看不见的独立任务，而是控制电脑端当前打开的 Codex 对话。当前会话文件即使正被 Codex 持续写入，也能按 Windows 共享规则安全读取；手机消息定位期间仍持续同步已经验证的会话，不会让消息链停摆。

## 启动与配对

1. 先打开并登录 Windows 版 Codex，进入你要控制的对话。
2. 保持发布文件夹完整，双击 `CodexMicroBridge.exe`；不要只移动一个 exe。
3. 等待右上角显示“桌面同步可用”。
4. 在“手机配对”页开放 60 秒配对窗口，用手机扫码。升级安装通常会保留原配对。
5. 手机和电脑连接同一个可信 Wi-Fi；局域网连接不需要 VPN。

## 使用方式

- 手机首页只显示一个“当前 Codex 桌面对话”。
- 手机发送文字时，桥接程序会定位 Codex 的当前输入框，写入完整文字，再在确认窗口仍属于 Codex 后执行发送。
- 桌面出现权限请求时，手机“桌面权限确认”会显示待确认项。V1.0.6 会过滤 Windows UI Automation 暴露的“确认/权限/审批”等界面碎片，只保留实际权限问题和必要上下文。长按批准后，桥接程序重新核对同一个审批控件，并只点击“允许此对话”；拒绝则只点击当前审批的“拒绝”，不会发送无条件回车，也不会误选“始终允许”。
- 手机“停止”对应当前桌面任务的停止按钮。
- 如果你在电脑端切换到另一个 Codex 对话，下一条手机消息将发送到新的当前对话。

## 安全与限制

- 这是一条经过证书指纹绑定和设备签名认证的局域网 WSS 链路；手机不会收到 OpenAI Token。
- 桥接程序只接受已验证的 Codex 桌面进程和可访问性控件，不使用固定屏幕坐标。
- 发送前必须确认 Codex 窗口、输入框与焦点仍然一致；审批前必须确认审批指纹仍然一致。状态变化时会拒绝操作，不会猜测。
- Windows UI 或 Codex 版本如果改变了输入框/审批结构，桥接会显示“桌面同步未就绪”，需要更新适配。
- 完整对话通过本机 Codex 会话记录同步回手机，包括手机发送、电脑直接发送和 Codex 回复；回复刚结束时可能有短暂刷新延迟。
- V1.0.1 不再使用项目白名单创建独立 App Server 任务；界面中的“旧版项目记录”仅用于查看或清理旧数据。

## 网络排查

若手机无法连接，请确认 Windows 网络为“专用网络”、两端处于同一局域网，且访客 Wi-Fi、AP 隔离、VPN 分流或防火墙没有阻断界面显示的 TCP 端口。诊断页只显示脱敏后的状态与异常类型。

版本：Codex Micro Desktop Sync V1.0.6（Windows + Android，局域网 WSS）。

V1.0.6 修复 V1.0.5 的严重回归：普通首行读取会与 Codex 正在写入的 rollout 文件发生 Windows 文件共享冲突，导致正确会话被误判为非主会话。新版统一使用共享读写方式读取元数据，等待精确手机提示时也不再停止已有会话同步；手机和电脑端新增消息与回复均能继续进入同一同步链。Bridge 只有在输入框和会话文件两层都可用时才报告“桌面同步可用”。
