# Codex Micro v2.0.2 — 新版标题栏兼容候选（Superseded Pre-release）

> **已被 V2.0.3 取代，不建议使用。** 手机发送成功、电脑回复完成后，本版可能把“查看活动，需要关注”等动态入口误认为对话标题，随后错误显示“电脑服务降级”。

> 没有独立可验证的精确完整源码快照；这是根据原始 Windows ZIP、哈希、更新说明和实机回归记录建立的候选归档。

## 原修复目标

新版 Codex Desktop 在对话标题所在的顶部区域加入了搜索、活动、项目入口、已安排任务和聊天操作等按钮。旧版 Bridge 按横向位置选取第一个文本控件，因此可能把“搜索”或“项目：…”误认为当前对话标题。

V2.0.2：

- 过滤新版标题栏的中英文系统按钮及“项目：/Project:”导航标签；
- 继续从真实对话标题匹配稳定会话 ID；
- 只在桌面可用性真实变化时记录诊断，避免每秒重复写入相同日志；
- 保留 V2.0.1 的六会话快照容量修复。

## 实机回归

用户实机确认本版能建立连接并同步六个对话；但手机发送消息、电脑完成回复后，标题栏短暂出现“查看活动，需要关注”，本版仍会误认标题并让手机显示“电脑服务降级”。WSS、证书、配对和局域网实际没有断开。

## 兼容性

- Windows Bridge：2.0.2。
- Android：继续使用 2.0.0，无需重装、清数据或重新扫码。
- 本版仅供历史追溯；该回归由 V2.0.3 修复。
