# Codex Micro v1.1.0 — 多对话隔离候选（Pre-release）

> 没有独立可验证的精确完整源码快照；这是根据原始二进制、哈希、更新说明和测试记录建立的候选归档。联合实机验收未完成，不应作为稳定版本使用。

## 主要变化

- 每个 Codex root rollout 使用独立稳定 threadId，移除所有桌面对话共用 `desktop-current` 的合并逻辑。
- 手机首页第一张卡尝试固定为当前可操作对话，下面显示最多五个最近对话。
- 回复历史、完成未读、运行状态和审批请求按对话隔离；subagent rollout 不进入列表。
- 历史对话只读，避免手机消息误发到电脑当前打开的其他对话。
- 审批中心显示所属对话，审批响应额外核验请求仍属于当前桌面对话。

## 验证边界与已知问题

- 原发布说明记录了 Windows、协议、Android JVM、Debug APK 与多 root 排序相关自动验证。
- Windows、Codex Desktop 与 Android 手机的联合多会话验收未完成。
- 后续版本仍发现会话归属、当前对话抢占和状态串线问题，本版本只保留为候选演进证据。
