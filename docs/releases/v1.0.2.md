# Codex Micro v1.0.2（历史版本）

> 该版本的自动验证曾通过，但 Windows + 红米 K80 Pro 实机验收失败，不推荐安装。仓库中对应标签是二进制证据归档，不声明包含完整 v1.0.2 源码。

## 主要变化

- Bridge 独立观察已绑定 Codex rollout 文件的长度和更新时间，文件变化后读取 canonical 用户与助手消息。
- 使用 `messageId` 幂等写入和推送，并抑制提前到达的 `event_msg` 镜像，避免重复回复。
- 首次绑定使用较大的尾部窗口恢复历史，后续监听缩小窗口以降低持续扫描开销。
- Android 提升为 `versionName 1.0.2`、`versionCode 11`，并开始强制执行与 v1.0.1 相同的签名连续性门禁。

## 已知问题与实机结论

- 电脑端新回复仍不能稳定即时到达手机。
- 审批结束后主页可能继续停留在“待审批”。
- 该版本仅保留为同步方案演进证据。
