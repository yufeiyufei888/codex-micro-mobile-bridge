# Codex Micro v1.0.5（历史版本：严重同步回归，不建议使用）

> **请勿安装该版本。** 自动测试曾通过，但 Windows + 红米 K80 Pro 实机测试确认消息同步链完全失效。对应标签是二进制证据归档，不声明包含完整 v1.0.5 源码。

## 原设计目标

- 手机发送后最多等待 45 秒，在 rollout 中完全匹配手机提示后再绑定正确 root 会话。
- 采用独立 300ms 文件轮询，将候选会话从 24 个增至 256 个，并排除 subagent rollout。
- WSS 在线但桌面控件不可用时，手机保留 Bridge 的权威降级状态。

## 严重回归与根因

- Codex 持续写入当前 rollout 时，Bridge 以普通 `File.ReadLines` 读取首行；Windows 文件共享冲突使正确 root 会话被误判为不可读或非 root。
- 手机发送后提前清除当前会话路径和文件游标，在等待精确提示的 45 秒内暂停已有会话同步。
- 实机最终表现为手机和电脑发送的新消息、回复都无法在手机显示。

## 验证边界

- 自动验证曾达到 Windows 80、Android 29、protocol 38 cases / 1 pair，但未发现上述活动文件共享与真实交互组合回归。
- 该版本只用于问题追溯，不推荐使用。
