# Codex Micro v1.1.1 — Goal/计划界面热修复候选（Pre-release）

> 没有独立可验证的精确完整源码快照；这是根据原始二进制、哈希、更新说明和测试记录建立的候选归档。后续仍观察到界面降级、当前对话抢占和状态串线，不建议作为稳定版本使用。

## 主要变化

- 将“Codex 窗口在线”与“普通输入框当前可写”拆分判断。
- Goal、计划和计划提问面板临时替换输入框时，尝试维持 WSS 与桌面窗口在线状态。
- 普通输入框不可用时明确禁止手机发送，避免误发到模式面板或其他软件。
- 当前对话优先按可见标题和 `.codex/session_index.jsonl` 匹配，降低后台任务抢绑定的概率。
- 计划选项继续要求在电脑端处理，不伪装成权限审批。
