# Generated Codex app-server schemas

This directory is a checked-in compatibility input for Codex Micro Mobile. The
current bundle was generated by Codex CLI `0.147.0-alpha.6.5` with:

```text
codex app-server generate-json-schema --out shared/app-server-schema/codex-0.147.0-alpha.6.5
```

The generated JSON files are vendor artifacts. Do not edit them by hand. Code
reviews should reject isolated edits inside the versioned bundle.

An upgrade is a compatibility change, not a routine regeneration:

1. Generate into a new `codex-<exact-version>` directory using the exact CLI
   intended for the release.
2. Add a new version lock with a deterministic directory digest.
3. Diff request, response, notification, enum, and approval shapes.
4. Update the app-server adapter and protocol fixtures where required.
5. Run the full compatibility and acceptance matrix in `docs/testing.md`.
6. Switch the active version only after review; keep the old bundle available
   until migration and rollback testing finish.

`version-lock.json` identifies the currently reviewed bundle using the exact
CLI version and a deterministic schema-bundle digest. It intentionally does not
bind a mutable WindowsApps executable path or file hash.

The directory digest is SHA-256 over this UTF-8 stream for every generated file
in ordinal relative-path order:

```text
<forward-slash-relative-path>\n<lowercase-file-sha256>\n
```

README and lock files are outside the versioned bundle and are not included in
that digest.
