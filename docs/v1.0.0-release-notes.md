# Codex Micro V1.0.0 正式版

V1.0.0 之前各个开发测试版本的新增、重写、修复和实机验证过程，见 [开发测试版本演进记录](./Codex-Micro-开发测试版本演进记录.md)。

## 已通过的实机验收

- 手机输入能够直接发送到电脑当前 Codex 对话，并收到回复。
- 电脑输入并发送时，手机保持绿色连接。
- 关闭再打开 Wi-Fi 后重连从第 1 次开始；再次断网仍从第 1 次开始。
- 长回复能够完整显示到 `【长回复结束】`。
- 手机长按批准桌面桥接的审批测试后，Windows 记事本成功启动。

## V1.0.0 界面收口

- 完成状态卡使用浅绿色状态底色，并保留图标、文字和连接类型。
- 完成状态卡不再重复回复正文，也不再显示持续滚动的进度条。
- 完整回复只在“最近回复”卡片中展示，避免同一消息出现两次。

## 尚需持续观察

- 红米 K80 Pro 在系统省电策略下的长时间后台连接仍受系统后台自启动、电池无限制和最近任务锁定设置影响。
- Codex Desktop 更新如果改变输入框或审批控件结构，桌面同步适配仍需跟随更新。
