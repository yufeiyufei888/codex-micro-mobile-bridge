# Codex Micro v1.0.0（历史基础版本）

> 首个完成核心实机验收的版本。对应标签是根据保留的二进制、发布说明、校验值和验收记录建立的历史归档，不声明包含完整 v1.0.0 源码。

## 已验收能力

- 手机向当前 Codex Desktop 对话发送消息并接收完整回复。
- 长回复显示正常。
- 两轮 Wi-Fi 断开与重连通过。
- Android 后台和锁屏连接保持通过。
- Bridge 审批测试中的批准、拒绝和一次性执行保护通过。

## 升级注意

v1.0.0 与 v1.0.1 及以后版本使用不同的 APK 签名，不能直接覆盖安装。升级时必须先卸载 v1.0.0，再安装新版本并重新配对；卸载会清除手机端本地配对和历史数据。
