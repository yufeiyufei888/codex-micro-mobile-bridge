# Codex Micro 桌面同步桥接（Windows）

这是 Android Codex Micro 的 Windows 伴随程序。V2.0.0 在桌面同步模式中以稳定会话 ID 和本地 JSONL 生命周期事件隔离当前对话与最多五个最近对话；同步消息、状态与审批时不再共用 `desktop-current`。

## 启动与配对

1. 先打开并登录 Windows 版 Codex，进入你要控制的对话。
2. 保持发布文件夹完整，双击 `CodexMicroBridge.exe`；不要只移动一个 exe。
3. 等待右上角显示“桌面同步可用”。
4. 在“手机配对”页开放 60 秒配对窗口，用手机扫码。升级安装通常会保留原配对。
5. 手机和电脑连接同一个可信 Wi-Fi；局域网连接不需要 VPN。

## 使用方式

- 手机首页第一张卡显示当前可操作的 Codex 对话，下面显示最近五个只读对话。
- 手机发送文字时，桥接程序会定位 Codex 的当前输入框，写入完整文字，再在确认窗口仍属于 Codex 后执行发送。
- 桌面出现权限请求时，手机“桌面权限确认”会显示请求所属对话，并过滤 Windows UI Automation 暴露的界面碎片。长按批准前，Bridge 会同时核对审批指纹和所属当前对话；切换到其他对话后旧审批会被拒绝，不会误批。
- 手机“停止”对应当前桌面任务的停止按钮。
- 如果你在电脑端切换到另一个 Codex 对话，下一条手机消息将发送到新的当前对话。

## 安全与限制

- 这是一条经过证书指纹绑定和设备签名认证的局域网 WSS 链路；手机不会收到 OpenAI Token。
- 桥接程序只接受已验证的 Codex 桌面进程和可访问性控件，不使用固定屏幕坐标。
- 发送前必须确认 Codex 窗口、输入框与焦点仍然一致；审批前必须确认审批指纹仍然一致。状态变化时会拒绝操作，不会猜测。
- Windows UI 或 Codex 版本如果改变了输入框/审批结构，桥接会显示“桌面同步未就绪”，需要更新适配。
- 当前对话与最近五个对话通过本机 Codex 会话记录同步回手机。V2.0.0 为每个 root rollout 生成独立 threadId，子代理 rollout 不作为手机对话展示；超出这六个会话的桌面历史不属于手机长期保存范围。
- V1.0.1 不再使用项目白名单创建独立 App Server 任务；界面中的“旧版项目记录”仅用于查看或清理旧数据。

## 网络排查

若手机无法连接，请确认 Windows 网络为“专用网络”、两端处于同一局域网，且访客 Wi-Fi、AP 隔离、VPN 分流或防火墙没有阻断界面显示的 TCP 端口。诊断页只显示脱敏后的状态与异常类型。

版本：Codex Micro Desktop Sync V2.0.0（Windows + Android，局域网 WSS）。

V2.0.0 继承 V1.0.6 已通过实机验证的实时回复和 Computer Use 审批链路，并继续重构会话聚合层：当前与最近五个 root rollout 的消息、未读状态、审批和历史分别保存；首页首卡为当前对话，最近对话按更新时间排列。状态以本地 JSONL 生命周期事件归一化；Goal、计划和提问卡片不会再把网络与会话同步误报为降级。Android 审批卡片改为简洁的结构化摘要，工作目录默认折叠。
