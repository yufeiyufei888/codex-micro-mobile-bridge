# Codex Micro v2.0.1 — 六会话快照容量热修复候选（Pre-release）

> 没有独立可验证的精确完整源码快照；这是根据原始 Windows ZIP、哈希、更新说明和测试记录建立的候选归档。该修复已被后续版本包含，不应作为当前稳定版本使用。

## 修复内容

V2.0.0 从旧版本升级时会继续读取本机数据库中的历史任务。若累计记录超过六条，Windows Bridge 仍执行旧的“最多六条，否则报错”断言，导致首次手机快照抛出 `InvalidOperationException`，随后主动中止 WebSocket。手机表现为持续显示“重连中”，重新配对或切换 Wi-Fi 均无法解决。

V2.0.1 改为：

- 从保留历史中稳定选择当前桌面对话、已有槽位对话和最近对话，最多同步六个；
- 任务数组和六个槽位由同一份选择结果生成，槽位不会引用快照中不存在的任务；
- 当前桌面对话优先占用同步容量；
- 超出手机同步范围的旧记录继续保留在电脑数据库中，不要求清库或重新配对；
- 首次连接、`tasks.list` 与后续权威快照共用相同规则。

## 兼容性

- Windows Bridge：2.0.1。
- Android：继续使用 2.0.0；协议与配对信息兼容，无需重新安装或重新扫码。
- 手机同步范围仍为当前对话加最近五个对话，共六个；这不是永久全量历史承诺。

## 验证边界

自动化覆盖 18 条保留任务缩减为六条移动端快照的升级回归场景，并验证 Windows 全套测试。真实手机通过局域网恢复连接未形成独立完整验收记录，因此本版保留为 Pre-release。
