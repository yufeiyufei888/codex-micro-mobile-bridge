# Codex Micro V1.0.4 更新说明

V1.0.4 是针对 V1.0.3 实机验收反馈的同步与界面修复版。V1.0.3 已验证真实 Computer Use 审批、批准后状态恢复、单次执行、后台连接和手机主动发送链路正常，本版保持这些行为。

## 修复内容

- 修复电脑端直接发送消息后，手机必须等到下一次主动发送才批量收到消息的问题。
- 根因是桌面开始新一轮任务时错误清除了已核验的会话文件绑定；现在同一对话会持续复用绑定，仅在实际切换对话标题时重选会话文件。
- Windows Bridge 清洗审批控件树摘要，过滤“确认、权限、审批、待批准、Computer Use”等通用界面碎片，保留实际问题，例如“允许 ChatGPT 使用 notepad?”。
- Android 对收到的审批摘要再次清洗，避免升级后本地残留或兼容数据重新显示碎片。
- 审批卡片改为明确的信息层级：审批状态、当前会话、请求标题、请求内容、工作目录、实际操作、批准与拒绝。
- Android 版本提升到 `1.0.4 (versionCode 13)`；Windows Bridge 文件版本提升到 `1.0.4.0`。

## 自动验证

- Windows：78 项自动化测试全部通过，包含同一对话保持会话绑定、切换对话重置绑定和审批摘要清洗用例。
- Android：28 项 JVM 测试全部通过，包含审批摘要清洗和标题去重用例；Debug APK 构建通过。
- 协议：38 个 canonical fixture 和 1 个 request/response pair 通过。

## 实机验收重点

1. 在手机保持绿色连接时，直接在电脑 Codex 输入框发送一条独立消息。
2. 不要在手机发送、刷新或重连，等待电脑回复。
3. 确认手机在数秒内自动显示该条电脑消息和回复。
4. 触发一次 Computer Use 审批，确认手机卡片只显示实际权限问题，不再出现竖排通用词碎片。
5. 长按批准后确认只执行一次、手机显示“已批准”、主页退出“待审批”。

自动测试不能替代 Windows + 红米 K80 Pro 的真实 Codex 窗口、WSS 和 Computer Use 联合验收。
